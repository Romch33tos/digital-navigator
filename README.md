# Цифровой навигатор

Прототип веб-приложения для студентов института Цифры, помогающий ориентироваться в вопросах академических задолженностей, получения справок и социальной помощи.

## О проекте

Проект реализуется в рамках дисциплины «Учебная практика». Это одностраничное приложение (SPA), которое служит цифровым гидом для студентов и помогает им искать ответы на интересующие их вопросы.

**Основные разделы:**
- **Академическая задолженность** – пошаговый маршрут закрытия долгов.
- **Справки** – информация о дирекции, кафедрах и профкоме с детальными инструкциями.
- **Частые вопросы (FAQ)** – быстрые ответы на типовые ситуации.

## Установка и запуск

Сайт автоматически деплоится на GitHub Pages при пуше в ветку `main` через GitHub Actions.

# Цифровой навигатор

Прототип веб-приложения для студентов института Цифры, помогающий ориентироваться в вопросах академических задолженностей, получения справок и социальной помощи.

## О проекте

Проект реализуется в рамках дисциплины «Учебная практика». Это одностраничное приложение (SPA), которое служит цифровым гидом для студентов и помогает им искать ответы на интересующие их вопросы.

**Основные разделы:**
- **Академическая задолженность** – пошаговый маршрут закрытия долгов.
- **Справки** – информация о дирекции, кафедрах и профкоме с детальными инструкциями.
- **Частые вопросы (FAQ)** – быстрые ответы на типовые ситуации.

## Реализованный функционал

### Умный чат-бот на базе GigaChat и RAG
- **Интеграция GigaChat API** через `langchain-gigachat` с использованием локальных эмбеддингов (`Xenova/all-MiniLM-L6-v2`) для построения векторного индекса.
- **База знаний в JSON** (`knowledge.json`): каждая запись содержит не только вопрос и ответ, но и сленговые алиасы («хвост», «закрыть долг», «деканат») и имена преподавателей, что решает проблему разрыва словаря между запросами студентов и официальными формулировками.
- **Гибридный поиск**: комбинирует векторный поиск по смыслу с точным совпадением ключевых слов (названия кабинетов, фамилии). Это позволяет находить нужный ответ, даже если запрос написан с опечатками или сленгом.
- **Разрешение контекста диалога (Query Rewriting)**: перед поиском бот анализирует историю переписки и переформулирует короткие или размытые сообщения (например, «учеба», «да долг у Степанова») в полноценный поисковый запрос.
- **Дружелюбный системный промпт** (вынесен в `prompts/system.txt`): учит бота корректно реагировать на приветствия, благодарности и эмоции, не выдумывать факты и честно признаваться, если ответа нет в базе.

### Структурированная база знаний
- Переход от плоского текста (`FAQ.txt`) к **формату JSON**: каждая запись — это законченный чанк, который не разрывается сплиттером и гарантирует точный семантический поиск.
- **Метаданные** (категории, алиасы, связанные сущности) позволяют масштабировать базу без потери качества поиска.

### Защита от «сжигания» токенов
- Внедрён **Rate Limiting** (`express-rate-limit`): ограничение 20 запросов в минуту с одного IP. Это защищает бюджет проекта от случайных или намеренных перегрузок.

### Улучшенный интерфейс чата
- Замена `<input>` на `<textarea>` с автоувеличением высоты (от 1 до 3 строк).
- Добавлен индикатор набора текста, плавный скролл и защита от повторной отправки, пока бот не ответил.
- **Яндекс.Метрика**: настроена отправка событий `CHAT_OPEN`, `CHAT_MESSAGE_SENT`, `CHAT_CLEAR_HISTORY` (с защитой от ошибок при недоступности `window.ym`).

## Технологический стек

- **Frontend**: React, React Router, Framer Motion
- **Backend**: Node.js, Express
- **AI/LLM**: LangChain, GigaChat API
- **Векторный поиск**: HuggingFace Transformers (локальные эмбеддинги), MemoryVectorStore
- **Аналитика**: Яндекс.Метрика

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск сервера
node server.js

# Запуск фронтенда (в отдельном терминале)
npm run dev
```

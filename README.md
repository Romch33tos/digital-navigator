# digital-navigator
Прототип проекта, реализуемый в рамках дисциплины "Учебная практика"

Для того чтобы поднять проект заново, нужно выполнить следующие шаги:

- Установить зависимости: npm install.

- Запустить локальный сервер разработки: npm run dev.

- Открыть в браузере адрес http://localhost:5173.

Убедиться, что данные загрузились и отображается главный экран с тремя карточками.
